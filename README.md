# Angular Essentials

Este curso proporciona una base sólida para aquellos que deseen empezar a trabajar con Angular y desarrollar aplicaciones web interactivas y dinámicas.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 1

- [Investigación sobre Angular](Capitulo01/README.md#investigación-sobre-angular)
  - Descripción: Realizar una investigación sobre Angular considerando su introducción, usos, ventajas y desventajas, versiones, marcos de trabajo MVC/Frontend, documentación, foros y comunidad.
  - Duración estimada: 48 min

### Capítulo 2

- [Instalación del software para el desarrollo con Angular](Capitulo02/README.md#instalación-del-software-para-el-desarrollo-con-angular)
  - Descripción: Instalar y configurar Node.js, NPM, TypeScript, Angular CLI, Visual Studio Code y un navegador para preparar el entorno de desarrollo con Angular.
  - Duración estimada: 49 min
- [Crea el proyecto Hola Mundo de Angular y verifica que funcione correctamente](Capitulo02/README.md#crea-el-proyecto-hola-mundo-de-angular-y-verifica-que-funcione-correctamente)
  - Descripción: Crear un proyecto Hola Mundo con Angular CLI y verificar su funcionamiento correcto en el entorno de desarrollo configurado.
  - Duración estimada: 49 min

### Capítulo 3

- [Programación con TypeScript](Capitulo03/README.md#programación-con-typescript)
  - Descripción: Desarrollar ejercicios de programación con TypeScript aplicando compilación, variables, tipos, operadores, estructuras de control, funciones, cadenas, arreglos, tuplas, módulos, enums y desestructuración.
  - Duración estimada: 26 min
- [Escribir un programa en TypeScript que defina una clase de Objetos llamada Libro](Capitulo03/README.md#escribir-un-programa-en-typescript-que-defina-una-clase-de-objetos-llamada-libro)
  - Descripción: Escribir un programa en TypeScript que defina una clase de objetos llamada Libro, aplicando los fundamentos de Programación Orientada a Objetos.
  - Duración estimada: 26 min

### Capítulo 4

- [Crear un componente simple que muestre el nombre de un usuario en la página web de la aplicación](Capitulo04/README.md#crear-un-componente-simple-que-muestre-el-nombre-de-un-usuario-en-la-página-web-de-la-aplicación)
  - Descripción: Crear un componente simple en Angular que utilice un template para mostrar el nombre de un usuario en la página web de la aplicación.
  - Duración estimada: 49 min

### Capítulo 5

- [Ciclo de vida de un componente en Angular](Capitulo05/README.md#ciclo-de-vida-de-un-componente-en-angular)
  - Descripción: Aplicar el ciclo de vida de un componente en Angular mediante la implementación y observación de sus etapas.
  - Duración estimada: 33 min

### Capítulo 6

- [Decoradores @Input](Capitulo06/README.md#decoradores-input)
  - Descripción: Aplicar el decorador @Input para recibir datos en un componente de Angular.
  - Duración estimada: 12 min
- [Comunicando un componente Hijo con su componente Padre utilizando @Output](Capitulo06/README.md#comunicando-un-componente-hijo-con-su-componente-padre-utilizando-output)
  - Descripción: Implementar la comunicación de un componente Hijo con su componente Padre utilizando el decorador @Output.
  - Duración estimada: 13 min

### Capítulo 7

- [Uso de Templates](Capitulo07/README.md#uso-de-templates)
  - Descripción: Construir templates en Angular aplicando interpolación de datos, directivas, event binding, variables de referencia, estilos, pipes y Bootstrap.
  - Duración estimada: 99 min

### Capítulo 8

- [Servicios en Angular](Capitulo08/README.md#servicios-en-angular)
  - Descripción: Crear y utilizar servicios en Angular, aplicando su definición e inyección para compartir funcionalidad o datos.
  - Duración estimada: 74 min

### Capítulo 9

- [Implementado Ruteo](Capitulo09/README.md#implementado-ruteo)
  - Descripción: Implementar ruteo en Angular mediante métodos de navegación, estrategias, mapeo, configuración, parámetros, redirecciones y comodines.
  - Duración estimada: 49 min

### Capítulo 10

- [Manejo de Módulos](Capitulo10/README.md#manejo-de-módulos)
  - Descripción: Diseñar y manejar módulos en Angular, incluyendo el uso de componentes en otros módulos.
  - Duración estimada: 197 min
